# Tabla de Aislación

App web para iPhone y Samsung: se elige la pipa y el espesor de aislación y muestra la letra, el diámetro, la circunferencia, el corte de lámina (+1.5, +2, +3) y las bandas (+6, +8).

Datos tomados de las tablas "Espesor de aislación" y "Medidas de aislación / Corte de lámina" del manual *Patrones de Aislación* (WH Rulers).

- Funciona sin internet después de abrirla una vez.
- Se instala desde el navegador: **Compartir → Agregar a pantalla de inicio** (iPhone) o **Menú → Agregar a pantalla de inicio** (Samsung).

Publicada con GitHub Pages: https://manuelavila2023.github.io/tabla-aislacion/
